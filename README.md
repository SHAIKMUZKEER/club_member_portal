## Build with Lovable

Continue developing this project in the [Lovable editor](https://lovable.dev/projects/9704874c-ad05-4227-8aab-a04236ec49c8).

## Development

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
